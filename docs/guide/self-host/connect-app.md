---
title: 在 APP 中连接
description: 读懂测试连接报告并完成自部署空间登录。
sidebar: { order: 7 }
---

1. 打开侧边栏「设置」，找到「服务与账号」。
2. 选择「自部署服务器」卡片，在「服务器地址」中原样粘贴向导输出的 APP 地址。
3. 点「测试连接」，查看下方检查结果；可连接时点「连接到这台服务器」。
4. 弹窗中按提示 [创建管理员](create-admin.md)，或填写已有账号，点「登录并连接」。

已登录一探官方时可直接这样切换，原空间数据保留，无须先删除或退出官方账号；见 [空间切换](../account-and-data/switch-spaces.md)。地址可带服务器要求的路径，但不要附加用户名、密码、查询参数或片段；除同机回环地址外必须 HTTPS。

| 检查项 | 含义 | 不通过时 |
| --- | --- | --- |
| 连接安全 | 地址、TLS 证书与安全连接条件 | 处理证书或地址问题，不能跳过校验 |
| 版本兼容 | APP 是否满足 `minClientVersion` 及服务合同 | 按提示升级 APP 或 Server |
| 实例状态 | 能否读取服务信息、身份与初始化状态 | 未初始化可创建管理员；不可达或身份变化需排查 |
| 登录方式 | 当前支持的密码登录及注册方式 | 只提供不支持的登录方式时不能连接 |
| AI | 实例是否声明已配置 AI | 不阻塞连接，不等于实时模型测试成功 |
| 头像 | 实例是否启用生成头像 | 不阻塞连接，与 AI 配置独立 |

测试连接不切换空间、不登录、不调用付费 AI 或 fal。编辑地址后报告失效，需要重新测试。确认连接后按提示初始化或登录；取消保留原空间。

如果实例迁到了新地址，APP 在验证其身份后可能提示「这是你之前的实例」。确认「改用新地址」保留原空间数据；活动空间可保留登录，非活动空间需重新登录。不要忽略同地址实例身份变更的错误。

失败时先看 [故障排查](troubleshooting.md)，版本规则见 [兼容矩阵](../reference/compatibility.md)。
