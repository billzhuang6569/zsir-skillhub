## 注册实例账号

1. 管理员打开自部署实例管理页的注册设置。
2. 选择邀请注册并生成邀请码。新码仅在本次响应中显示明文，及时通过可信方式交给成员；重新打开页面只显示掩码。
3. 将实例地址与注册邀请码交给成员。成员在 APP 连接同一实例，按注册表单填写邮箱、显示名称、密码和邀请码。
4. 管理员在成员列表确认新成员；确有需要时再将其设为管理员，最后一个管理员不能被降级。

默认邀请模式没有邀请码时关闭注册，也可主动选择关闭。显式环境变量覆盖时界面只读；`LOCAL_REGISTRATION_ENABLED=false` 始终禁止注册。注册邀请码与初始化码不同，不能用来创建首个管理员。

## 加入团队

实例注册后仍需加入具体团队。在「团队」创建团队，由所有者生成团队邀请链接。对方打开链接并登录目标实例后加入；跨实例会先要求确认连接和登录，不会静默切换。

邀请链接绑定签发时的实例与地址，有有效期；实例换地址或链接过期后重新生成。注册邀请码不授予团队成员资格，团队链接也不代替实例账号注册。
