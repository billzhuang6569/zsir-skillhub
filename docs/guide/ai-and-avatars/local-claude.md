当前本机推理**只支持 Claude Code 2.1.x，且 patch 不低于 300**，例如 2.1.300、2.1.301；2.1.299 及以前、2.2 及以后均不在当前支持范围。版本范围来自本机运行器合同，不表示 CLI 厂商承诺兼容。

Codex CLI 当前不支持本机推理，因为无法可靠关闭用户指令与账号级 MCP 连接器，不能满足隔离要求；这不影响它作为 Skill 安装目标使用。

1. 在本机安装受支持版本的 Claude Code，并在其自身入口登录。
2. 在已登录的自部署空间打开「AI 服务 → 使用本机 Agent」。
3. 执行检测，查看安装、版本、登录、最小调用与隔离检查。检测本身会运行最小分析请求，也会消耗供应商额度。
4. 检测成功后启用本机方式及自动分析。APP 运行期间顺序处理本人未分析的 Skill；偏好按当前设备、空间与账号保存。

实例已配置 AI 接口时优先使用服务器，本机选项不可选。重开 APP 后需要重新检测。当前不提供本机模型列表选择。

本机推理使用 Claude Code 已登录账号的服务，是否计入订阅或其他额度、可用量及限制由供应商决定，SkillHub 不承诺免费或无限额度。它不消耗实例 AI 接口的日次数；头像最终出图仍需 [fal Key](fal-key.md) 并由 fal 计费。

运行器使用独立临时目录，不向推理进程传递 Skill 钥匙和团队凭据。支持版本不等于所有 Windows 登录环境均已实测；检测失败时保留手工编辑，不尝试降低隔离设置。
