---
title: 配置 fal.ai Key
description: 自部署管理员验证 fal 认证并开启头像生成。
sidebar: { order: 3 }
---

1. 使用自己的 fal.ai 账号取得 Key。
2. 自部署管理员在设置的「Skill 头像」中填写 Key，点测试。
3. 测试成功后保存；超过 10 分钟、修改 Key 或保存失败后须重新测试。
4. 保存成功后检查头像服务状态，再选择风格。

`FAL_KEY` 环境变量优先于界面配置，存在时界面不能保存或删除设置。普通成员只能看服务状态，不能查看 Key。

**测试仅验证认证，不生成图片，也不写入配置**；通过不代表已验证付费出图、余额或未来可用性。生成费用由 fal 收取，SkillHub 展示的估算不是最终账单。

删除界面配置不会删除已有头像、任务或历史。无有效 Key 时不启动新的付费生成；已有图片仍可使用。自部署头像可以用直接提示词生成，不强制依赖实例 AI 接口。

建立云端作者记录的 Skill 会由服务器自动补齐头像；配置了 AI 时先分析，只有 fal 时可直接生成，仍受每日额度及每账号每小时 60 次登记限制。已有图片、自定义头像、已有任务或身份冲突不会被扫描重画。历史本机任务缺少可信云端绑定时，需要管理员核对身份；扫描不会猜测绑定或重复付费。
