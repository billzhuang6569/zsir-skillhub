---
title: 第一次打开 APP
description: 选择服务、发现 Agent 并导入第一个 Skill。
sidebar: { order: 3 }
---

1. 打开设置，确认服务选择：默认是一探官方，也可选择仅本机或连接自部署服务器。
2. 查看本机 Agent 检测结果。刚安装了 Agent 时点重新检测；目录未确认时先处理覆盖目录设置，不能靠手工建目录冒充安装。
3. 打开「我的 Skills」，选择「导入 Skill」，选含 `SKILL.md` 的文件夹或 ZIP。
4. 阅读预检结果，有冲突时先决定是否取消、改名或接管，确认后再导入。
5. 打开 Skill 详情，安装到已检测到的 Agent；需要 API Key 时到「钥匙」填写并完成授权。

本机使用可先不登录、不配置 AI。自部署未配置 AI 时保留显式元数据并显示未分析，未配置头像服务时仍能管理 Skill。

当前步骤使用设置与导入页面；不依赖尚未接入的首次启动分步导览。下一步看 [管理 Agent Skills](../guides/manage-agent-skills.md)。
