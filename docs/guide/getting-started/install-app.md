---
title: 下载安装
description: 根据电脑系统与芯片选择 SkillHub 桌面安装包。
sidebar: { order: 1 }
---

1. 打开 [SkillHub 官网下载区](https://sk.woe.show/#download)。
2. macOS 选择 Apple Silicon 或 Intel；Windows 选择 x64 或 ARM64。按下载页提示安装并打开 APP。
3. 若 Mac 提示文件损坏，先核对包的芯片版本，再使用对应官网下载页给出的处理步骤，不运行来源不明的修复命令。
4. 打开「我的 Skills」，按 [第一次打开 APP](first-open.md) 完成初次导入。

SkillHub 不替你安装 Agent。先安装需要使用的 Agent，再在设置中重新检测；仅有 Skills 文件夹不算已安装。支持范围见 [能力列表](../reference/agent-capabilities.md)。

本机导入、查看版本、安装到 Agent 无需登录。跨设备同步与团队共享需要在相应服务器登录。
