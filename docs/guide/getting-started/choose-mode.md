---
title: 三种使用方式怎么选
description: 按数据存放位置与维护责任选择一探官方、仅本机或自部署。
sidebar: { order: 2 }
---

| 能力 | 一探官方 | 仅本机 | 自部署 |
| --- | --- | --- | --- |
| 本机导入、版本、安装到 Agent | 有 | 有 | 有 |
| 账号同步、团队共享 | 登录后使用 | 无 | 登录自己的实例后使用 |
| 个人钥匙与本机运行 | 有 | 有 | 有 |
| 服务端 AI 分析与生成头像 | 按官方服务状态 | 无 | 管理员自行配置 |
| 官方商店浏览与安装 | 有 | 主动访问时可用 | 主动访问官方商店 |
| 服务器与备份维护 | 官方负责 | 无服务器 | 自己负责 |

希望马上开始，选一探官方；只整理当前电脑，选仅本机；需要自己的账号、存储与服务配置，选自部署。**仅本机模式与在本机部署 Server 是两件事**：后者仍有数据库、账号和备份责任。

从旧版本升级后继续使用一探官方，不需要重新选择，原有账号登录与数据保持不变。

在设置中的服务选择区域切换。切换保留原空间数据，不自动复制到新空间；返回原空间需重新登录。详见 [空间切换](../account-and-data/switch-spaces.md)。

仅本机仍会检查 APP 更新，主动打开商店时会访问官方目录和安装包；它不是完全断网开关。
