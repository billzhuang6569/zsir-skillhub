---
title: 登录一探账号
description: 使用系统浏览器登录官方空间并回到 SkillHub。
sidebar: { order: 1 }
---

1. 在设置中选择「一探官方」。
2. 点「登录账号」，在打开的系统浏览器中完成一探账号登录。
3. 回到 APP，确认显示的是自己的账号，再使用账号同步、团队与投稿。

APP 与 CLI 共用当前账号状态，CLI 没有第二套密码登录入口。浏览器登录取消或超时时，在 APP 中重新发起。

官方账号恢复使用一探账号门户。SkillHub 当前没有自己的邮件验证与邮件找回密码流程。自部署账号与一探账号独立，不能用相同邮箱自动合并；见 [空间切换](../account-and-data/switch-spaces.md)。
