---
title: 官方提供的服务
description: 了解官方空间的账号、商店、AI 与媒体服务边界。
sidebar: { order: 2 }
---

| 服务 | 用途 | 可用性 |
| --- | --- | --- |
| 账号与同步 | 保存账号内的 Skills，跨设备同步 | 需要登录与网络 |
| 团队 | 邀请成员、共享固定版本、讨论与团队钥匙 | 按成员权限使用 |
| AI 分析 | 生成 Skill 简介、分类、标签等资料 | 以实例 `features.ai` 和实际请求结果为准 |
| Skill 头像 | 生成头像；支持的模式下选择风格 | 以 `features.avatars` 与界面为准 |
| 图片托管 | 个人、团队及 Skill 图片 | 官方使用 Picem 适配器；不是用户可任意上传的通用图床 |
| 官方商店 | 公开浏览、安装与审核后发布 | 官方实例声明 `features.marketplace=true` |

能力信息来自 `server/src/server-info.ts`。声明能力不证明上游供应商此刻可用，也不承诺无限额度。官方用户无需在 SkillHub 填写实例 AI 或 fal 密钥。

头像和专题封面可能使用公开图片地址；反馈截图使用受保护读取。不要用公开头像承载私密内容。自部署则默认使用自己的媒体存储，见 [对象存储](../self-host/object-storage.md)。
