在两台设备安装 SkillHub，连接同一空间并登录同一个账号。登录后先看到完整列表，文件后台逐个下载；未上传修改先上传或保留副本，避免静默覆盖。只有加入该账号的 Skill 参与同步。

## 前提和步骤

1. 两台设备安装 [对应架构的 APP](../getting-started/install-app.md)，登录同一服务器的同一账号。
2. 在登录状态导入 Skill，或从商店、团队安装；未登录、其他账号或来源不明的本机内容须显式加入当前账号。
3. 保持两台设备联网，等待文件下载完成。仅看到列表不代表文件已经可用。
4. 在每台设备分别安装到该机实际检测到的 Agent。

自部署安装官方商店 Skill 的账号绑定还要求实例提供 `catalogInstall`；旧实例可能只保留本机文件，见 [商店](marketplace.md)。

## 同步如何保护修改

同步比较文件内容、可执行路径及资料与账号基线，相同内容不重复上传。替换目录前先保护本机修改：上传成功或保存为副本后才替换。APP 内编辑、安装与同步共用锁；对外部编辑器的改动在替换前再次校验。切换账号后，旧任务不能继续写入新账号。

```sh
skillhub sync status --json
skillhub sync --json
skillhub sync --retry --json
```

`status` 是本机保存的状态，不是 Server 实时确认。`sync` 可能上传、下载或处理账号删除；`--retry` 请求重试问题项，不是强制覆盖冲突。

## Windows 的区别

账号与回收站规则一致。Windows 显示解析后的绝对路径，识别的 Agent 集合与 macOS 不同，部分只按 CLI 检测。同步 Skill 不等于把另一台设备的 Agent 安装状态照搬过来。

## 删除和恢复

从账号删除会同步到其他设备，离线设备下次联网处理。误删可在设置的账号回收站恢复，已有团队或商店发布版本不受此操作影响。

已同步 Skill 不能只从某台电脑删除来永久省略同步；CLI 删除预检会拒绝账号同步条目。若要由某个工具自己管理，使用 APP 的「交给工具自行管理」，工具获得独立副本，账号原件继续同步。

## 哪些内容不同步

SkillHub 配置的个人钥匙值只保留在各自本机，不随 Skill 同步；每台设备分别提供。这个保证不覆盖写进 `SKILL.md`、脚本或配置文件的硬编码秘密，它们属于文件内容。未加入当前账号的 Skill 也不参与同步。

原指南未进行真实 Mac 与 Windows 双设备演示，本次文字迁入也不代表新增双机验收。本机保存成功或服务端有条目，均不能证明离线设备已更新。

## 常见问题

### 为什么有列表却不能运行

文件还在下载；等待完成并查看错误状态，再安装到本机 Agent。

### 两台电脑都修改了怎么办

同步先保护修改并可能保留副本，核对两份内容后再处理；不要用重试当作强制覆盖。

### API Key 会自动到另一台电脑吗

个人钥匙不会随 Skill 自动同步。团队钥匙由运行时按权限获取，是另一条授权路径。

### 仅本机能跨设备同步吗

不能。需连接同一服务器并登录同一账号。
