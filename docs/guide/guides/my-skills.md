title: 我的 Skills
description: 查看当前空间的 Skill、同步进度、版本和 Agent 安装状态。
sidebar: { order: 4 }
---

「我的 Skills」围绕当前空间与账号展示内容；「本地」可发现当前电脑上的其他内容，但文件存在不授予其他账号的云端身份与权限。

1. 使用搜索、标签、分组或 Agent 筛选定位 Skill。
2. 查看版本编号、「已修改」与下载状态。下载完成后才可使用文件。
3. 打开详情阅读 `SKILL.md`，查看附带文件、需要的钥匙与安装位置。
4. 编辑时使用 APP 或 CLI 安全编辑会话；保存版本后再决定共享或投稿。

删除前分清范围：停用 Agent 投影、交给工具自行管理、从账号删除是不同动作。从账号删除会传播到其他已登录设备，可在设置的账号回收站恢复；交给工具自行管理保留独立副本，账号原件仍同步。

见 [导入已有 Skill](import-skill.md)、[同步规则](sync-skills-mac-windows.md)。
